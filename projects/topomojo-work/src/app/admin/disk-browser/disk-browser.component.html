Template VMs

Proxmox template VMs that templates can clone from. Copy a name into the template field of a template's Detail on the Templates tab. Copies tagged for deletion and the per-template copies TopoMojo makes when a template is unlinked are not listed.

Disks

Disk files in the hypervisor's disk store that templates can use. Copy a path into the disks list of a template's Detail on the Templates tab. Deployed VM disks and extent/snapshot files are not listed.
