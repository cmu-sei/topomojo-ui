Template VMs

Proxmox template VMs that templates can clone from. Copy a name into the Template value of a template's Detail on the Templates tab. Global template VMs are shared bases; workspace template VMs are the copies TopoMojo makes when a template is unlinked. Copies tagged for deletion are not listed.

Disks

vSphere VMDK disk files in the disk store that templates can use. Copy a path into a Disks[].Path value of a template's Detail on the Templates tab. Deployed VM disks and extent/snapshot files (-flat, -delta, -000001, ...) are not listed.
